# Morning Exercise

A personal web app for building an exercise habit at a Singapore fitness corner during a morning coffee walk, at home with his kids, and a separate kettlebell session at home. Success is opening the app, seeing an approachable workout and starting it immediately.

## Constraints

- Phone first, often outdoors. Instructions must be readable and controls easy to tap.
- No onboarding, account, goal picker, dashboard, history screen or workout saving. The sole goal is building the habit.
- Finishing or ending returns immediately to the selected session’s original overview with **Start workout** ready. There is no completion page, effort feedback, saved-visit message, daily lockout, progression or automatic recovery routine. Each start resets the timer and movement order.
- The default 2-minute-40-second routine has exactly five movements: 8 platform push-ups, 8 knee raises, a 10-second pull-up bar hang, a 10-second parallel-bar hold and 8 squats. Eight seconds of preparation and four 15-second rests are included. Keep all original repetition and hold targets. The former Time preset control is retired; use Edit session for explicit timing changes.
- A header selector switches between **Morning**, **At home** and **With kids** without setup. **Exercise with kids** is a default 85-second session: Get ready 5 seconds, jumping jacks 20 seconds, rest 20 seconds, squats 20 seconds, rest 20 seconds. One preparation phase, with no extra rounds. Completion and End return to this same selected session, ready to restart. Selection lasts for the current page visit only.
- **At home** is an exact 520-second session: prepare15, incline push-ups20, rest15, kettlebell swings20, rest15, trampoline120, rest15, packing with squats300. No kettlebell squat phase. The overview shows four activities with two- and five-minute labels and a 15-second prep/rest note. All eight phases are editable. Packing is normal packing for five minutes, using a comfortable squat only for floor pickups, not continuous squats. Trampoline uses gentle low bounces; the packing example reuses the bodyweight squat demo. Settings stay independent of Morning and With kids.
- **Edit session** opens a simple editor for the selected session: choose an existing exercise type, change its seconds, add or remove steps, and Save changes. Get ready and Rest are editable steps too. The live total includes every step; allow 1–600 whole seconds per step, at least one exercise, at most 20 steps and no more than 10 minutes total. Back discards a draft. Restore original routine previews the default in the editor and needs Save to apply.
- Edited session configurations are remembered on this browser; completed workouts are never recorded. Custom routines are timed, with all steps shown in their exact order. The original morning routine retains its rep targets until edited. Retired time preferences cannot override the new Morning targets or rests. Every overview has **Bare minimum · 20s squats**: five seconds of prep, then twenty seconds of bodyweight squats, with no rest or rep target. It replaces the former one-minute shortcut, never changes saved settings, and returns to the same selected overview after completion or End. Legacy visits and feedback drafts are ignored; existing stored records are left untouched. Without browser storage, workouts still start and reset normally.
- The default morning session has no floor exercises, pull-ups, dips, jumps or drops. With kids includes the explicitly requested jumping jacks; At home includes the requested kettlebell movements and incline push-ups. Keep movement guidance, rest breaks, Pause, and stop-for-pain instructions.
- Preparation and rest use a distinct teal background, explicit Get ready / Rest headings, and a countdown labeled for the current phase. Show an animated preview of the next actual exercise with its name and station, looking past any intervening prep/rest steps. Preview time never consumes exercise time. Final rest has no preview and says All movements done. Pause, guidance, hiding the tab and Reduce Motion also stop previews.
- A quiet **Skip** text button beside End workout advances exactly one step (including prep and rest), resets the next phase timer and updates the remaining time. Skipping while paused keeps the next step paused. Skipping the last step returns to the selected overview ready to start again; it never saves or edits the routine.
- Bell, voice cues, pixel demonstrations, background motion controls and Reduce Motion remain available. Prep and rest announce “Next exercise” followed by the next actual movement name, using bundled audio for every exercise type. Wait for the full name to finish before speaking countdown numbers; skip expired numbers instead of queueing them. Final rests have no invented next exercise. Start, pause/resume, guidance and lifecycle cancellation remain consistent.
- Tone: calm, direct, encouraging without pressure or invented fitness claims. Familiar operation with one primary action per screen.
- Visual identity: Ninja Arena, the user's chosen athlete/obstacle-arena style with navy, red and cyan, oversized athletic type and moving course lines.

## Delivery

Buildless HTML/CSS/JavaScript in `dist/`. Tests use Node's standard runner. The GitHub repository is connected to the existing Vercel project at https://morning-exercise-sg.vercel.app. Verify Git-triggered deployments; if none appears, stage a production CLI deployment, verify its assets and promote it.

Configuration compatibility: keep the `on-the-way.sessions.v1` storage key, write payload version 3, and read versions 1, 2 and 3. Older version-1/2 At home settings are retired so the newly requested eight-phase routine loads on existing devices; future version-3 edits remain exact. On loading version 1, change Morning rest steps to 15 seconds without changing exercises or other sessions. Preserve a legacy routine if the migration would exceed the 10-minute editor limit. Version-2/3 explicit Morning edits retain their exact rest durations. No automatic storage writes occur during migration.
