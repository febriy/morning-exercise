# Exercise sprite atlas

Created with the built-in `image_gen` tool, transparent background enabled. Original output is preserved as `exercise-source.png`. Final runtime assets: `dist/sprites/platform-pushup.png`, `dist/sprites/hanging-knee-raise.png`, `dist/sprites/support-hold.png`.

The source was sliced into four poses per movement with FFmpeg, transparently padded onto aligned 400px squares, then scaled to 200px with nearest-neighbour sampling and stacked horizontally. Runtime clips the 800 × 200 strips into square frames; no GIF timers or dependencies are needed.
