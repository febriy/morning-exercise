# App icon

User-selected icon: 💪. The iPhone Home Screen icon (`dist/apple-touch-icon.png`,180×180) and favicon (`dist/icon.png`,32×32) render the actual Apple Color Emoji glyph on the existing opaque midnight-navy background. iOS applies its own icon shape. The former SVG URL also shows the emoji. No workout screens or controls change.

Rendered offscreen with macOS AppKit/Apple Color Emoji at74% of canvas width, centred, background#07172e. No generative image tool or external image service used.

[Apple webpage-icon documentation](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html).
