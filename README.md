# Morning Exercise

A small exercise-habit app for a coffee walk past a Singapore fitness corner. The default routine uses a push-up platform, a pull-up bar and parallel bars. Two more sessions run at home: **Exercise with kids** and a separate **At home** kettlebell routine.

## Experience

Open the app → see the workout → Start. No first-run setup or goal picker. The default morning routine is two minutes; its Time button changes the preset. **Edit session**, beside the duration, changes exercise types and seconds for each session. The header switches between **Morning**, **At home** and **With kids**, with no extra setup.

The normal two-minute routine is the user’s requested sequence: **8 platform push-ups → 8 knee raises → 10-second pull-up bar hang → 10-second parallel-bar hold → 8 squats**. The timer gives 8 seconds to prepare, 24 seconds for each set of reps, 10 seconds for each hold, and four 5-second rest/transition windows. Total: 120 seconds. Rep targets are ceilings, not a requirement to rush: stop early or pause for more rest and station changes. Hands stay elevated for push-ups, hang and support holds stay steady, and squats use a clear level standing area. No floor work, pull-ups, dips, jumps or drops. The one-minute small routine keeps the five movements at 3 reps each and 5-second holds, with preparation and rests.


The default **Exercise with kids** session is exactly **5 seconds Get ready → 20 seconds jumping jacks → 20 seconds rest → 20 seconds squats → 20 seconds rest**, once through, for 85 seconds total. The kids session has no Time preset control. Selecting it does not change the morning time preference.

The default **At home** session is **5 seconds Get ready → 20 seconds kettlebell squats → 20 seconds rest → 20 seconds incline push-ups → 20 seconds rest → 20 seconds kettlebell swings → 20 seconds rest**, once through, for **125 seconds** total. The overview groups the three movements and states the preparation/rest timing; the editor shows all seven phases. Kettlebell squats hold a bell close to the chest, incline push-ups use a fixed raised support, and two-handed swings use a hip hinge with the bell no higher than chest height. Time presets remain exclusive to the default Morning session.

Finishing or tapping **End workout** returns immediately to the selected session’s original overview, ready for **Start workout** again. There is no workout-save step, feedback, completion screen, daily credit, progression, recovery-day substitution or resumed feedback draft. Every start resets the timer and phase order of the selected routine, including edited routines. All three defaults start with preparation (five seconds for With kids and At home). Session selection is kept in memory for the current page visit only. The completion bell and voice still play; an accessible status announces the return without adding a screen.

Time changes persist under `on-the-way.preferences.v1`, as `{timeBudget}`. When this preference is absent, the current legacy profile's valid time choice can be read from `on-the-way.v1`. Legacy visits, levels and `on-the-way.pending.v1` drafts do not affect the app and are left untouched. Blocked storage does not prevent exercising. Settings do not sync between devices.

The session editor uses native exercise selects and numeric seconds fields. Choose from the nine exercise types plus Get ready and Rest, add or remove steps, check the live total, then Save changes. Back discards unsaved changes. Restore original routine loads a draft of the default; Save applies the reset. Editing a session creates an exact timed sequence without rep targets or hidden prep/rest phases. An unchanged default Save preserves the original rep targets and writes nothing. Custom morning routines hide the preset Time control so it cannot silently replace edited timings. All overviews offer **Bare minimum · 20s squats**: five seconds of prep then twenty seconds of bodyweight squats, without equipment, rep targets or a final rest. This replaces the former one-minute shortcut. It never changes any routine or stored settings, and completion or End returns to the selected overview.

Edited configurations persist separately under `on-the-way.sessions.v1` as `{version:1,morning?:[{id,seconds}],kids?:[{id,seconds}],home?:[{id,seconds}]}`. Loading validates each session independently and ignores malformed settings and unknown fields. Inputs require whole seconds from 1 to 600, at least one movement, no more than 20 steps, and no more than 600 seconds total. Only Save writes configuration; Start, completion and End do not write visits. Blocked storage applies changes in memory with an explanatory notice. Cross-tab configuration changes pause an active workout without replacing its current timer, and preserve an open draft.

The timer pauses when backgrounded or interrupted. Tapping Start unlocks a soft bell and bundled English trainer voice clips. A bell marks the beginning of the session, each phase boundary and completion. The voice says Get ready, Start, Rest and Workout complete, and counts the final five seconds of longer phases. Short phases prioritize their opening cue, then count the remaining seconds. Pause, guidance, End workout, a hidden tab and page navigation cancel pending cues. Resume restarts the current phase cue without replaying elapsed countdowns. The nine voice clips total about 30 KB and do not require installed device voices or a speech-service account. Browser speech is a fallback if clips cannot load. On Safari versions supporting the Audio Session API, Start and Resume select the playback session before opening Web Audio, avoiding the ambient route that iPhone Silent Mode can mute. Pause, page backgrounding and completion restore the previous session type after pending audio has ended. Older browsers continue with their existing audio behavior. Visual cues remain available; audible volume depends on device sound settings. Keep the app visible while exercising. The navy Ninja Arena background moves gently between workouts. Use its header pause control to stop it; it also stays still during a workout, in a hidden tab, or when Reduce Motion is enabled.

Small 8-bit movement previews appear in the routine list. During a strength step, the same pixel-art man demonstrates the movement beside the timer. Push-ups, knee raises and squats repeat on a three-second demonstration cycle; both the pull-up bar hang and parallel-bar support stay still. The hang reuses the knee-raise atlas’s initial straight-arm pose; squats have a matching new four-frame atlas. Demo poses follow the existing workout clock, pause with it, and do not restart on resume. Reduce Motion shows a static pose. Preparation and rests keep their own timer but preview the next exercise beside it, with a prominent Next title and station. The full background and timer panel turn teal for preparation/rest; their status explicitly says Prep time left or Rest time left. Preview frames follow the current break clock and reset when the actual exercise starts, so previewing never spends exercise time. The lookup skips intervening prep/rest phases and follows custom session edits. Final rests show All movements done with no invented next movement. Guidance during a preview describes that upcoming movement; opening it still pauses. Active exercise phases and the overview retain the original navy background. Artwork was generated with the built-in image-generation tool; the original atlas and complete prompt are saved in `assets/sprites/` and the five transparent four-frame strips are in `dist/sprites/`. The added squat source and exact generation prompt are saved as `assets/sprites/squat-source.png` and `assets/sprites/SQUAT-PROMPT.md`. Jumping jacks use a matching front-view four-frame strip on a two-second demonstration cycle; its source and exact prompt are `assets/sprites/jumping-jacks-source.png` and `assets/sprites/JUMPING-JACKS-PROMPT.md`. Timed demos show the movement without imposing a rep target.

These low repetition counts and short hold durations are personal app choices, not a validated clinical prescription. Movement references: [NASM incline push-up](https://www.nasm.org/resource-center/exercise-library/incline-push-up) and [Catalyst Athletics hanging leg raise and scaling options](https://www.catalystathletics.com/exercise/45/Hanging-Leg-Raise/). Concerning pain or unusual symptoms mean stop; professional guidance is appropriate where needed.

## Development

```sh
node --test tests/*.test.mjs
node --check dist/app.mjs
python3 -m http.server 8791 --bind 127.0.0.1 --directory dist
```

Buildless HTML/CSS/JavaScript; no API keys, account system, analytics, GPS or uploads. Production: https://morning-exercise-sg.vercel.app — deployed to Vercel on 22 October 2026. The two-minute routine is available over HTTPS without the Mac or shared Wi-Fi. Source: https://github.com/febriy/morning-exercise. Vercel serves `dist/` using the root `vercel.json`. Deploy from this directory with `vercel deploy --prod`. The GitHub repository is connected to the existing Vercel project. The Git integration is configured for `main`, but its trigger did not run for the last release. Verify the deployed commit rather than assuming a push shipped. If necessary, use `vercel deploy --prod --skip-domain`, verify staged asset hashes with `vercel curl`, then `vercel promote` the staged production deployment. `.vercel/` contains ignored local project linking. The selected time and edited session configurations are stored per browser and origin. Workouts are not recorded.

Safari audio routing reference: [WebKit issue 251532](https://bugs.webkit.org/show_bug.cgi?id=251532), including its recommendation to select `navigator.audioSession.type = "playback"`. The regression fixture models the documented Silent Mode routing behavior; it does not substitute for an audible check on a physical iPhone.

The kettlebell squat and swing use matching four-frame RGBA sprite strips generated with the built-in image tool. Exact prompts, form sources and derivation notes: [KETTLEBELL-PROMPTS.md](assets/sprites/KETTLEBELL-PROMPTS.md). Runtime assets are `dist/sprites/kettlebell-squat.png` and `dist/sprites/kettlebell-swing.png`; source strips are in `assets/sprites/`. Incline push-ups reuse the platform push-up strip. The clock drives these previews and they freeze on pause, guidance, backgrounding and Reduce Motion. The images illustrate form rather than imposing a repetition speed.
